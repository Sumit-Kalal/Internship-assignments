# Axilex Internship — Work Repository

This repository contains the projects, exercises, and assignments completed during an internship with the Axilex group of companies. The work is organized by month and week to track progress through the internship curriculum.

## Overview
- Purpose: Store and demonstrate code, exercises, and small projects completed as part of the Axilex internship.
- Audience: Axilex mentors, future reviewers, and the repository owner.

## Repository Structure (high level)
- Month-01/: Beginner Python exercises organized by week and day.
- Month-02/: Web and backend examples (Flask/Express-style files and app scaffolds).
- Month-03/: Frontend projects, TypeScript, and build tooling (Vite, server scripts).

Each Month/Week/Day folder typically contains focused examples and README files explaining the contents of that folder.

## Languages & Technologies
- Python (scripts, exercises)
- JavaScript / TypeScript (frontend and backend examples)
- HTML / CSS (static pages and small web demos)

## How to run examples
- Python scripts: open a terminal in the folder and run `python script_name.py` (use your environment's Python 3 interpreter).
- Node/TS projects: follow the individual folder's README; typically `npm install` then `npm run dev` or `npm start` is required.

If you want me to run or package any specific project in this repo, tell me which folder and I will provide exact commands.
